# Lettuce Analysis

## Overview
This project explores a lettuce dataset using Python, with a focus on data handling, image processing, counting, and visualization.

## Tools and Libraries

- **Python** — programming language used for the analysis.
- **Pandas** — data manipulation and analysis.
- **Matplotlib** — creating graphs and visualizations.
- **Pillow (PIL)** — opening and working with images.
- **Collections.Counter** — counting and tallying items.
- **OS** — interacting with the operating system, including file and directory operations.
- **Google Colab** — notebook environment used for development.

## Objectives
- Explore and organize the lettuce dataset.
- Work with image files using Python.
- Count and summarize dataset items.
- Use visualizations to communicate relevant findings.

## Project Files
- `greenhouse_lettuce.ipynb` — Jupyter notebook containing the analysis.

## Getting Started
1. Open the notebook in Google Colab.
2. Set up the dataset and file paths required by the notebook.
3. Install any required libraries that are not already available.
4. Run the notebook cells in order.
